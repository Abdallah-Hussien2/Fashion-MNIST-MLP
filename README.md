# Fashion-MNIST Classification using MLP

## Problem Description

This project implements a Multilayer Perceptron (MLP) neural network using PyTorch for Fashion-MNIST image classification.
The model classifies clothing images into 10 categories such as shirts, shoes, bags, and dresses.

---

## Dataset Link
https://github.com/zalandoresearch/fashion-mnist

## Results

| Model | Learning Rate | Test Accuracy | Test Loss |
|---|---|---|---|
| Model 1 | 0.001 | 86.83% | 0.3593 |
| Model 2 | 0.01 | 83.75% | 0.4726 |

## Techniques Used
- MLP Neural Network
- ReLU Activation Function
- Dropout Regularization
